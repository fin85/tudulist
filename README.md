# ТудуЛист

Персональный PWA для задач из Google Sheets.

## Возможности MVP
- задачи из Google Sheets;
- фильтры;
- дедлайны Asia/Yerevan;
- отметка выполнения с записью обратно в таблицу;
- автообновление раз в час;
- PWA;
- заготовка для Web Push.

## Подключение Google Apps Script
1. Создать проект Google Apps Script.
2. Скопировать `apps-script/Code.gs`.
3. Развернуть как Web app: Execute as Me, доступ Anyone with the link.
4. Скопировать URL `/exec`.
5. Вставить его в `config.js` → `apiUrl`.

## Публикация
Репозиторий можно импортировать в Vercel как статический сайт без build-команды.

## Push
Фоновая отправка уведомлений за 24 ч / 5 ч / 30 мин будет подключена следующим этапом.
